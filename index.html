// ПРОТОКОЛ ЧТЕНИЯ

Чтение — это и есть прицеливание. Держи ПКМ: время растягивается, а перекрестье снимает паттерн цели. Пока цель не прочитана, руки чужие — разброс огромен, урон вполовину.

Окно. У каждого паттерна есть уязвимая фаза. Прочитанная цель показывает колесо паттерна: попадание в окно — протокол, мгновенное устранение.

Фокус тратится на растяжение времени. Пополняется устранениями.

Переселение (F). Прочитанное тело можно занять. Это единственное лечение: патроны и целостность приходят только с новым телом. Каждое переселение увеличивает дрейф.
