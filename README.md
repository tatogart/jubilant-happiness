# ПРОТОКОЛ НИША

FPS, где прицеливание — это чтение врага.

Ты — не тело. Ты — то, что читает тела. Каждую миссию ты входишь в чужого носителя,
снимаешь паттерны узлов охраны и переселяешься дальше. Сюжет про то, чьё тело настоящее,
если ты меняешь их каждый сеанс.

Игра — один HTML-файл и папка со скриптами. Ни сборки, ни зависимостей, ни ассетов:
геометрия рисуется собственным рейкастером, текстуры, спрайты и звук синтезируются при запуске.

## Запуск

Открыть `index.html` в браузере. Всё.

Если браузер капризничает с `file://`, поднимите любой статический сервер:

```sh
python3 -m http.server 8000     # затем http://localhost:8000
```

Нужен Chrome, Firefox, Safari или Edge последних лет. Мышь захватывается по клику
(Pointer Lock), Esc возвращает в паузу.

## Управление

| | |
|---|---|
| `WASD` | движение |
| `ПКМ` / `Shift` | **чтение** — растягивает время и снимает паттерн цели |
| `ЛКМ` | огонь |
| `F` | переселение в прочитанное тело (и выбор ниши в финале) |
| `R` | перезарядка |
| `Пробел` | рывок |
| `Esc` | пауза |

## Как это работает

**Чтение — это и есть прицеливание.** Кнопка чтения занимает то же место, что ADS в любом
шутере, и нажимается в том же ритме — фаза наблюдения встроена в обычный флоу, а не вынесена
в отдельную механику.

Пока цель не прочитана, руки чужие: разброс огромен (`unreadSpread`), урон — 40% (`unreadDamage`).
Держишь чтение — время замедляется до 0.2 (сам ты двигаешься на 0.58), перекрестье снимает
паттерн за 1.0–1.6 с, и по мере снятия разброс падает до нуля, а урон растёт до полного.

**Окно.** Паттерн каждого узла — это цикл фаз: обход → захват → очередь → сброс → подача.
Одна фаза помечена как уязвимая. У прочитанной цели видно колесо паттерна со стрелкой текущей
фазы и таймером «ОКНО ЧЕРЕЗ 0.8С»; попадание в окно — **протокол**, мгновенное устранение
вне зависимости от здоровья.

**Фокус** — ресурс растяжения времени: тратится, пока время растянуто, возвращается
от устранений (и вдвое больше — от протоколов). Кончился — время щёлкает обратно
в самый неудобный момент.

**Переселение.** Прочитанное тело можно занять (`F`, дистанция 7.5). Это единственное лечение
в игре: целостность и патроны приходят только с новым телом, на полу не валяется ничего.
Каждое тело — свой набор: скорость, запас целостности, оружие.

| тело | целостность | оружие |
|---|---|---|
| НУЛЕВОЕ | 100 | ШЁПОТ — пистолет |
| ТЕЛО ХОРА | 85 | ШЁПОТ |
| ТЕЛО ПИЛЫ | 115 | ПИЛА — когти, ближний бой |
| ТЕЛО КЛЕРКА | 62 | ИГЛА — снайперская |
| ТЕЛО ХИРУРГА | 155 | РАСКОЛ — дробовик |
| ТЕЛО ЭХА | 120 | РОЙ — автомат |

**Распад.** Когда целостность носителя доходит до нуля, есть 1.7 секунды предельного
замедления, чтобы прыгнуть в прочитанное тело. Не успел — сеанс окончен.

**Дрейф.** Каждое переселение +1 к дрейфу: чтение чуть ускоряется, максимум фокуса падает,
интерфейс начинает рвать по строкам, а в наушниках появляются чужие воспоминания.
Чем ты лучше читаешь тела, тем меньше остаётся тебя.

## Узлы

| узел | повадка | окно |
|---|---|---|
| **ХОР** | очередь из трёх, слышит соседей | подача магазина |
| **ПИЛА** | сжимается и бьёт рывком в упор | раскрутка после рывка |
| **КЛЕРК** | долгая наводка, мгновенный выстрел | остывание |
| **ХИРУРГ** | медленно подходит и стреляет веером | продувка |
| **ЭХО** | смещается рывками и **читает тебя в ответ** | пересборка |

Если ЭХО дочитало тебя, его разброс падает, а урон растёт — ровно то же, что делаешь ты.

## Сеансы

1. **ИНИЦИАЛИЗАЦИЯ** — узел связи, первые паттерны
2. **АРХИВ ТЕЛ** — опись носителей, клерки на дистанции
3. **ЛИТЕЙНАЯ** — цех переплавки, пилы и хирурги
4. **ХОР** — общий контур: снимаешь одного, сбиваются все
5. **НИША** — два пустых тела и выбор, который закрывает историю (две концовки)

Прогресс, дрейф и текущее тело сохраняются в `localStorage`.

## Устройство кода

Классические `<script>`-теги без сборки, общее пространство имён `window.NISHA`.

| файл | что внутри |
|---|---|
| `js/util.js` | математика, детерминированный ГПСЧ, `localStorage` |
| `js/audio.js` | весь звук: WebAudio-синтез, гул уровня, приглушение на замедлении |
| `js/input.js` | клавиатура, мышь, Pointer Lock |
| `js/textures.js` | процедурные текстуры стен/полов/потолков и спрайты фигур |
| `js/raycaster.js` | DDA-рейкастинг стен, каст пола и потолка, билборды, постобработка |
| `js/defs.js` | **весь баланс**: тайминги чтения, фокус, оружие, тела, паттерны |
| `js/maps.js` | сеансы в виде символьных сеток и разбор в карту |
| `js/story.js` | брифинги, осколки памяти носителей, концовки |
| `js/entities.js` | узлы и их паттерны, снаряды, взвесь |
| `js/player.js` | движение, чтение, стрельба, переселение, распад |
| `js/game.js` | мир сеанса: симуляция, навигация, правила миссии, сборка кадра |
| `js/hud.js` | перекрестье, кольцо чтения, колесо паттерна, метки, миникарта, оружие в руках |
| `js/ui.js` | экраны, меню, сохранение |
| `js/main.js` | запуск и главный цикл |

Крутить баланс проще всего в `js/defs.js` — там лежат `TUNE`, `WEAPONS`, `BODIES`, `ENEMIES`.

### Проверка карт

```sh
node tools/check-maps.js      # прямоугольность, глухой периметр, достижимость всех узлов и выходов
node tools/debug-map.js 2     # карта достижимости конкретного сеанса в терминал
```

`check-maps.js` возвращает ненулевой код, если сетка кривая или до узла/выхода нельзя дойти,
так что его можно повесить в CI.

### Настройки

В меню: внутреннее разрешение (320×180 … 800×450), чувствительность, инверсия по Y,
громкость, режим (ЧИТАТЕЛЬ / ОХОТНИК / БЕЗ ТЕЛА) и стирание прогресса.
Кадр рендерится в низком разрешении и растягивается без сглаживания — отсюда и вид, и 60 кадров.
